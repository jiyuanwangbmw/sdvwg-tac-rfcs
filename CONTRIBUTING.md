# Contributing to the Eclipse SDV WG TAC RFCs

Thank you for your interest in contributing to the Eclipse SDV WG TAC RFC
process.

## Before You Begin Contributing

### Licenses

Contributions are made under the licenses identified in this repository. By
submitting a contribution, you represent that you have the right to do so under
those terms. See [COPYRIGHT](COPYRIGHT) and the repository license files for
details.

### Code of Conduct

Please review and adhere to the [code of conduct](CODE_OF_CONDUCT.md) before
submitting a pull request.

## Contribution Process

Substantial proposals must follow the RFC process in [README.md](README.md).
Corrections and other non-substantive changes may be submitted directly as pull
requests.

All submissions, including submissions by TAC members, require review. We use
GitHub pull requests for this purpose. Consult [GitHub
documentation][pull-requests] for more information.

### Issues

To report a problem or discuss an idea before preparing a pull request, open a
GitHub issue.

[pull-requests]: https://docs.github.com/en/pull-requests
